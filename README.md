# Network and Cybersecurity Home Labs

This repository contains hands-on labs from a six-month network engineering and cybersecurity development plan.

## Labs

- [Lab 2 — VLANs and inter-VLAN routing](Lab-02-VLAN-Inter-VLAN-Routing/README.md): Packet Tracer build guide, sanitized Cisco configuration examples, and evidence templates.

Build and verify each lab in an isolated simulator before treating the example configurations as validated. Add your own Packet Tracer files and screenshots only after removing personal information and secrets.
